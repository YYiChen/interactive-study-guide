# Engineering Domain · 工科与工程数学

`domain=engineering` 是**默认领域**。本文件不新增学习规则，只把 core 规则收敛成工程资料的具体口径——原来写在 `SKILL.md` §10、§14 与 `core/references/*` 里的工程示例集中到这里。

## 1. 适用资料特征

- 固体/材料力学、动力学、振动、热力学、流体、传热、电路、控制、工程数学、微分方程等课程；
- 载体：课件 PPT、实验指导书、往年卷、习题解答、公式表、Lab Guide / 报告模板、教师板书照片；
- 内容形态：概念 + 符号 + 方程/公式 + 条件 + 推导 + 题型。

## 2. 加载清单

1. `../../core/README.md` 与 `../../SKILL.md`（全部 core 规则）；
2. 本文件（组织轴、图型例子、验证重点）；
3. 涉及具体课程时按需读 `../../core/references/teaching-architecture.md`、`content-rules.md`、`verification.md`。

## 3. 学科主线（示例，不是强制模板）

模型应根据当前课程的对象与任务识别最自然的结构：

- 力学类常见：对象/几何/受力 → 方程 → 条件 → 求解 → 解释；
- 热流体类常见：系统/控制体 → 守恒 → 物性/本构/状态关系 → 假设 → 求解；
- 数学类常见：定义 → 性质/定理 → 推导/证明 → 方法 → 例题。

不要把任何一个示例当成强制模板；依赖顺序仍由 Prerequisite Graph 决定，不由课件目录决定。

## 4. 图型判定（core §14 的工程口径）

| 图型 | 工程典型例子 | 默认要求 |
|---|---|---|
| **A 结构识别类** | 设备演示、部件示意、装置照片、装配关系、流程框图 | **静态**；读者任务是“认出这是什么、在哪、怎么组合”，动效不增加理解 |
| **B 查表取值类** | Moody 图、K_L 表、等效粗糙度表、当量比、ε–NTU 关系、符号/单位速查 | **优先可交互查表**：给一个可调量（Re、ε/D、φ…），实时高亮对应行/曲线并显示完整数值 |
| **C 关系演化类** | 参数敏感性、时间演化、几何关系、图形读法、方法对比、量级感 | **必须可交互**（滑块 / 播放暂停 / 拖动），静态图只作降级兜底 |

C 类的工程判定口径（防误判）：

- “几何关系”指**拖动会改变量与量之间的关系**（拖位置看力臂、拖长度看剖面）；只展示固定结构的是 A 类；
- 表格二分：对比/收束型（易错对照、符号汇总、方法对比）静态；查表取值型（给一个量查另一个量）按 B 类；
- 一张图兼有两类性质时按更高级别处理（C > B > A），但不得因此把 A 类设备图强行加戏；
- 典型 C 类触发场景：“参数变大，根会怎么移动”“振荡怎么衰减”“从衰减曲线上量出 δ”“换个摆长周期怎么变”。

图容器、四种交互代码骨架、静态降级与图注三要素见 `../../core/references/interactive-patterns.md`。

## 5. 内容口径

- **记号**：上下标、点号、偏导、向量、矩阵必须解释；同一符号在不同章节含义变化时重新声明（`../../core/references/content-rules.md` §2）；
- **公式角色**：定义 / 基本定律 / 本构 / 推导 / 经验 / 近似必须明确，可行时做量纲或极限检查（同上 §3）；
- **推导**：可省略熟练读者显然的机械运算，但不能省掉新方法首现、关键替换、边界/初值进入位置、近似理由、数学结果回到物理含义（同上 §4）；
- **经验关系与近似**：说明来源、适用范围、为什么当前可用、超出范围会怎样（同上 §5）；
- **数值检查**：能否回代、是否满足守恒/方程/边界（`../../core/references/verification.md` C 节）。

## 6. 原型与练习

- 默认结构原型 `exam-prep`（例题与训练必备）；
- 实验/原理讲解用 `principle`（默认关闭例题训练）；考前压缩用 `review`；
- 练习梯度与 Solution-backward Audit 见 `../../core/references/teaching-architecture.md` §6–§7。

## 7. 不做

- 不把某门课的具体公式写进 `core/` 或本文件当全局规范；
- 不把旧版“每题必须 prep”“每页固定自检”等已废止规则带回来；
- 具体教学事故写成案例放 `../../core/references/case-studies/`，并抽象成可迁移规则。
