# Material Taxonomy · 雅思资料类型判定

## 1. 两个正交维度

每条资料登记两个维度，不要只贴一个标签：

- **来源角色**（谁产出的）：教师讲解 / 课堂补充 / 个人总结 / 练习与作答 / 参考材料 / 未知；
- **内容性质**（里面是什么）：方法技巧 / 语言素材 / 示例与范文 / 经验与提醒 / 评测线索 / 混合 / 未知。

一份文件通常是混合的：按章节或条目拆成多条 material record，而不是给整份文件贴一个标签。

## 2. 类型判定表

| 类型 | 判定信号 | 典型载体 | 进入系统的形态 | 注意 |
|---|---|---|---|---|
| 教师讲解 | 成体系的分类、术语定义、系统讲授 | 课件、讲义 | 概念 / 方法节点 | 课程口径，优先作为主口径 |
| 课堂补充 | 临场例子、口头强调、题外话、括号里的短句 | 笔记片段 | 归入对应节点，标“课堂补充” | 最容易在整理中丢掉，属高价值信息 |
| 解题方法 | 步骤、策略、判断顺序、时间分配 | 技巧页、批注 | 技巧节点（必须对应一个可执行动作） | 落不到动作上的“方法”要降级为素材或待定 |
| 语言素材 | 词汇、搭配、句式、连接词、同义替换 | 词表、摘抄 | 挂在功能 / 话题节点下的素材清单 | 不单独成页堆积，必须有使用场景 |
| 高频表达 | 被标注“常用 / 必背 / 高频”的表达 | 加粗、星标、反复出现 | 素材清单 + 频次证据 | “高频”必须有来源，不能由模型断言 |
| 示例分析 | 范文、范例作答、题目解析、批改 | 范文、改稿 | 案例节点（原文 + 分析） | 原文完整保留，不得改写后冒充资料 |
| 个人经验总结 | 第一人称、复盘、教训、自定规则 | 复盘笔记 | 经验节点，标“个人口径” | 与教师口径分开记，冲突时并存 |
| 练习材料 | 题目、题库、作业、模考 | 题库、试卷、题卡 | 训练来源（题干与答案分开存） | 不把练习当知识节点 |
| 未知 | 看不出属于哪类、碎片、无标题片段 | 零散片段 | 待定记录 | 见 §4 |

## 3. 记录字段

`material_id`、`label`（文件名或来源名）、`carrier`（课件 / 手写笔记 / PDF 解析产物 / 截图 / 音频转写）、`origin`（课次、日期、老师、教材名）、`role`、`content_kind`、`locator`（页 / 段 / 题号 / 时间码，有多少记多少）、`coverage_state`、`relation_to_existing`（new / 补充 / 修订 / 重复 / 冲突）、`notes`。

解析产物（PDF/DOCX/PPTX 经解析得到的 Markdown + 图片目录）按“**一个来源一条记录**”登记，不要把每个分块文件当成独立来源。

## 4. 未知类型怎么办

`unknown` 是合法且常见的状态：

- 先登记证据（它在说什么、出现在哪、被谁强调），不强行归类；
- 不因为“看起来像词汇表”就按词汇表处理；
- 同一内容在后续材料里再次出现并变得清楚时，再提升为具体类型（走 `incremental.md`）。

## 5. 反模式

- 按文件名判类型；
- 整份笔记只贴一个标签（丢掉混合结构）；
- 把“高频表达”整理成一张没有出处的词表；
- 把个人总结写成教师口径，或把教师口径写成个人推断；
- 一次出现就升级成“必考 / 高频”。
