# Page Patterns · 语言学习页面表达

结构原型由**读者任务**决定（`../../core/references/page-archetypes.md`）。本文件只补语言学习特有的表达口径与视觉锚点定义。

## 1. 内容原型（节点级）

| 原型 | 读者任务 | 必备内容 | 不适合 |
|---|---|---|---|
| 概念解释型 | 搞清“这是什么、什么时候用” | 定义 → 为什么需要 → 与相邻概念的区别 → 最小例子 | 用来放纯素材库存 |
| 技巧总结型 | 学会一个可执行动作 | 触发信号 → 动作步骤 → 常见误用 → 一次示范 | 讲成原理长文 |
| 案例分析型 | 看懂别人怎么做、为什么这样改 | 原始材料（题干 / 范文 / 作答）→ 分析 → 可迁移的点 | 只给结论不给原文 |
| 对比型 | 分清容易混的两三样 | 对照维度表 → 判定问句 → 各自例子 | 把不相关的东西并排 |
| 复习速查型 | 考前快速调取 | 决策树 / 清单 / 对照表，并指回正式节点 | 第一次讲新知识 |

原型是**动态选择**的：不同知识节点可以不同原型；同一节点只有一个 Canonical Teaching Location。

## 2. 与 core 结构原型的映射

结构原型仍只有四个：`exam-prep` / `principle` / `review` / `custom`（checker 依赖它，不要自造值）。

| 内容原型 | 推荐结构原型 |
|---|---|
| 概念解释型 / 案例分析型 | `principle`（默认不含例题训练）；需要练习时用 `exam-prep` |
| 技巧总结型 | `exam-prep`（带练习）或 `review`（纯速查） |
| 对比型 / 复习速查型 | `review` |

页面声明两个属性：`<body data-archetype="…" data-domain="ielts">`，并在顶部注释写清：读者任务、内容原型、为什么这样裁。

## 3. 视觉锚点（core §14 的语言学习落地）

每个知识板块至少 1 个视觉锚点。语言学习的锚点不是示意图，而是**结构化视图**：

| 类型 | 语言学习里的例子 | 默认要求 |
|---|---|---|
| **A 结构识别类** | 题型结构图、文章 / 语篇结构、答题流程、评分维度表、界面与操作截图 | 静态 |
| **B 查表取值类** | 题型→策略对照表、band 描述表、连接词 / 词伙分类表、同义替换表、场景词表 | **优先可交互查表**：选一个条件，实时高亮对应行并显示完整内容 |
| **C 关系演化类** | 时间与题量的节奏分配、定位路径、错误模式随条件变化、同义替换网络、模板可变槽位 | **必须可交互**（滑块 / 切换 / 拖动）；静态图只作降级兜底 |

**语言素材卡**（例句对照、搭配卡、替换族）是合法的 A 类锚点，但必须是结构化视图（表格 / 卡片 / 网络图），不能是一段普通文字。

图注三要素照写：它让什么变得可见 / 应观察什么 / 结论是什么。

## 4. 表达纪律

- **原文完整**：引用题干、范文、教师原话时保留原文（可短），改写只用于解释；
- **对错成对**：错误例与改正例并排，标清错在哪一步；
- **答案默认折叠**：`<details class="answer">`；练习题不给题型标签；
- **不编内容**：没有音频、范文或评分标准材料时，**不得**自己生成“标准听力材料 / 范文 / 官方标准”冒充资料；模型补充要标明是补充；
- **中英混排**：原文用英文，解释用中文；同一术语全页统一写法；
- **分数与官方口径**：没有材料支撑时，不做 band 分数断言。

## 5. 不做的交互

- 为动而动的动画与装饰性效果；
- 需要联网、TTS 或 ASR 才能成立的“口语 / 听力交互”（除非用户明确要求并提供了素材）；
- 超过 3 个主动参数的控件；
- 用折叠隐藏结构问题（折叠只降低同时可见的信息量）。

## 6. 反模式

- 把工程课页面模板原样套到语言材料上（不必要的公式块、坐标轴图注）；
- 每个题型一个独立页面，彼此重复；
- 把答案写在题干旁边；
- 把个人总结伪装成官方评分标准。
