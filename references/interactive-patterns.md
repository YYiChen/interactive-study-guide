# Interactive Patterns

交互是教学工具，不是装饰。

## 1. 适合做交互的情况

### 参数敏感性
拖动一个参数，观察结果、曲线、区域或数值如何变化。

### 时间演化
播放/暂停，观察状态随时间变化。

### 几何关系
拖动位置、角度、长度或边界，观察几何量与公式结果同步变化。

### 图形读法
允许用户在曲线/图上定位、量取、识别区域或读取关键值。

### 方法对比
同一输入下切换两种近似、模型或数值方法，看差异和适用范围。

这些模式可用于力学、热流体、数学等多类课程。

## 2. 不适合做交互的情况

- 只是为了“页面更酷”；
- 静态图已经足够；
- 交互结果无法保证和公式一致；
- 动效会掩盖核心概念；
- 参数太多导致读者不知道该看什么。

## 3. 最低要求

每个交互旁必须写：
- 它让什么变得可见；
- 应观察什么；
- 最终结论是什么。

数值显示、曲线、文字结论必须相互一致。

## 4. 可访问性

交互要有清晰标签，关键结论不能只靠颜色或动画表达。

即使 JS 失效，静态页面也应保留核心知识。
