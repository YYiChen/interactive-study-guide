# Interactive Patterns · 交互与图规范

交互是教学工具，不是装饰；但"工具"也意味着**不该出现时不出现**。本页第一件事不是"怎么加交互"，而是**先给图定型**。

两条前置约束：

1. **角色先于形式**：每张图先归入 `evidence`（原始证据图）/ `teaching`（结构教学图）/ `demo`（状态演化演示）之一。分级只决定"要不要交互"，不决定"用哪种图"；原始证据图一般不重做成交互，考试口径优先保留原图。
2. **正确性先于交互**：静态结构正确、必要信息可见、可读性达成之前，不进入交互设计。凭文字想象连线再用交互掩盖，是最坏的组合（见 `visual-material.md` §5、`SKILL.md` §13）。

## 1. 先分三类，再定交不交互

每张图/表格动手前先归类：

| 图型 | 典型例子 | 默认要求 |
|---|---|---|
| **A 结构识别类** | 结构图、部件/关系示意、流程框图、实物或界面照片、装配关系 | **静态**。读者任务是"认出这是什么、在哪、怎么组合"，动画不增加理解 |
| **B 查表取值类** | 参数表、分级表、对应关系表、符号/术语速查 | **优先可交互查表**：给一个可调量，实时高亮对应行/曲线并显示完整数值；做不到完整交互时，最低限度让"可调范围与详细数值"可见 |
| **C 关系演化类** | 参数敏感性、时间演化、几何关系、图形读法、方法对比、量级感 | **按学习收益选择**：需要主动改变参数/状态时交互；状态对照或连续帧足够时可静态，保留清楚结论 |

判定口径（防误判）：

- "几何关系"指**拖动会改变量与量之间的关系**（拖位置看力臂、拖长度看剖面）；只展示**固定结构**的是 A 类，不是 C 类；
- 表格二分：**对比/收束型**（易错对照、符号汇总、方法对比表）静态；**查表取值型**（给一个量查另一个量）按 B 类；
- 图兼有多类性质时，按读者当前任务选择表达，不按 C > B > A 自动升级为交互；
- 分级判的是**当前学习任务**，不是素材本身的属性：源图内容"随时间变化"并不自动要求把它重做成交互；只有当读者必须观察状态演化才能完成当前任务时，才归 C 类。

各领域的典型例子与判定口径见对应领域适配器：工程（Moody、K_L、ε–NTU、Re/ε/D/φ 等）见 `domains/engineering/domain.md` §4；IELTS 等语言学习资料（题型/策略对照、band 描述表、同义替换网络、节奏分配等）见 `domains/ielts/page-patterns.md` §3。

## 2. C 类：什么时候交互确有收益

下列情形是交互候选，不是自动触发器。先判断学生是否需要主动操控才能完成学习任务；能用正确的状态对照、连续帧或图上标注讲清时可静态表达。guided 优先可运行骨架，autonomous 可自行设计；用户明确要求交互时应实现已授权目标，遇到真实能力限制则说明缺口：

1. **参数敏感性**：一个参数变化会改变结果、曲线形状、区域或数值——"参数变大，根会怎么移动"这类问题用文字描述成本很高；
2. **时间演化**：现象是过程性的——"谁先稳定下来""振荡怎么衰减"；
3. **几何关系**：拖动位置、角度、长度或边界，几何量与公式结果同步变化；
4. **图形读法**：需要训练"从图上读一个量"的技能——"从衰减曲线上量出 δ"；
5. **方法对比**：同一输入下切换两种近似 / 模型 / 数值方法，看差异和适用范围；
6. **量级感**：数字跨越几个数量级或反直觉——"换个摆长周期怎么变"。

原则：两种执行路径的自由范围与检查停止条件见 `execution-profiles.md`。交互要回答一个**具体问题**，且读数必须**与公式自洽**（用户会拿手算对照）。宁可少而准；不能可靠核验的交互改用有依据的静态表达。

## 3. 不适合做交互的情况

- 只是为了"页面更酷"；
- **A 类图**：设备演示、部件示意、流程框图、只需识别名称/结构的图——静态是正确选择，不是偷懒；
- 交互结果无法保证和公式一致（算不清就不要交互，改静态图 + 文字结论）；
- 动效会掩盖核心概念；
- 参数太多导致读者不知道该看什么（超过 3 个主动参数的交互重新设计）。

## 4. 最低要求（每个交互 / 每张图都要有）

图注三要素，缺一不可：

1. **它让什么变得可见**；
2. **应观察什么**；
3. **最终结论是什么**（静态结论，不依赖交互也能读到）。

其他硬要求：

- 交互旁必须有静态结论；JS 失效时核心知识不丢失（静态图作为降级兜底，见 §6）；
- 数值显示、曲线、文字结论相互一致，读数必须等于公式计算值；
- 关键结论不能只靠颜色或动画表达；交互控件有清晰文字标签；
- 配图按 `visual-material.md` §2 的视觉需求判定，纯定义/代数无需为配额加图：读者必须看见结构/连接/方向/波形才能完成的任务，都要有对应图，不能靠板块内任意一张图替代；
- 每张图声明编号与角色（`data-fig-id` / `data-fig-role="evidence|teaching|demo"`），便于增量更新时定位；
- 交互必须检查**代表性状态与边界状态**（参数最小/最大、正/负半周、开/关、线性/饱和），不能只演示一个好看的中点。

## 5. 四种可抄的代码骨架

所有模式共用两条工程纪律：

- **每个交互独立 `(function(){ … })()` 自执行 + 元素守卫**（`if(!el) return;`），一个交互出错不影响其他交互与导航；
- **初始化也要跑一次** `upd()`，否则首屏读数与图形不同步。

### 模式 1：滑块联动（参数 → 曲线 + 读数）

```html
<div class="diag" id="demo-slider" style="text-align:left;">
  <div style="font-size:13px;margin:0 16px 6px;">🎛 <b>参数探险器</b>：拖动滑块看曲线与读数怎么变</div>
  <div style="display:flex;flex-wrap:wrap;gap:14px;justify-content:center;align-items:flex-start;">
    <svg id="sSvg" width="430" height="250" viewBox="0 0 430 250" role="img" aria-label="参数-结果曲线"><!-- 静态轴/标签 --></svg>
    <div style="min-width:250px;">
      <div>参数 a = <b id="sAv">1.00</b>
        <input type="range" id="sA" min="0.1" max="3" step="0.05" value="1" style="width:100%;accent-color:var(--accent);">
      </div>
      <div id="sInfo" style="font-size:12.5px;color:var(--muted);"></div>
    </div>
  </div>
  <div class="cap">交互 · 它让“参数如何改变结果”变得可见；观察曲线形状与读数；结论：……</div>
</div>
<script>
(function(){
  var s = document.getElementById("sA"); if(!s) return;
  var info = document.getElementById("sInfo");
  function upd(){
    var a = parseFloat(s.value);
    /* ① 按公式计算 → ② 更新图形属性 → ③ 更新读数（读数必须等于公式值） */
    document.getElementById("sAv").textContent = a.toFixed(2);
    info.innerHTML = "当前结果：<b>" + /* 公式计算值 */ + "</b>";
  }
  s.addEventListener("input", upd); upd();
})();
</script>
```

### 模式 2：分量分解（把“总量”拆成可见的组成部分）

画两条分量曲线（虚线）+ 一条合成曲线（实线），让“相加”这件事看得见。适用于“两个常数相加”“慢项 + 快项”这类关键理解点。要点：图注写明“虚线相加 = 实线”，并给每条曲线一个能口述的名字。

### 模式 3：播放式动画（时间过程）

`requestAnimationFrame` 推进时间，渐进绘制曲线并移动游标；按钮控制播放 / 暂停 / 重播。

```javascript
var playing = false, i = 0, last = 0;
function frame(ts){
  if(!last) last = ts;
  var dt = Math.min(0.05, (ts - last) / 1000); last = ts;   // dt 封顶，否则切页回来跳帧
  if(playing){ i += dt / DURATION * N; if(i >= N){ i = N; playing = false; } }
  // 用 arr.slice(0, Math.floor(i)) 生成局部 polyline，并移动圆点
  requestAnimationFrame(frame);
}
requestAnimationFrame(frame);
```

结束时把按钮文案改成“↻ 重播”。

### 模式 4：连续循环动画（运动 / 能量）

`rAF` 里递增相位并重画：运动部件、折线、能量条宽度同时更新。要点：视觉尺度要标注（如“动画已加速 ×3”），避免读者误判真实快慢；给“暂停 / 继续”按钮。

## 6. 图容器契约与静态降级

- 图统一用 `.diag` 容器 + `.cap` 图注（模板已含样式），SVG 手写内联：坐标轴 + 单位 + 正方向 + 关键标记；
- **容器契约**（可选，但推荐；页面声明 `data-visual-contract="v1"` 后 checker 会严格校验）：
  - `data-fig-id="FIG-…"`：全页唯一，增量更新与替换时用它定位；
  - `data-fig-role="evidence|teaching|demo"`：图的角色；
  - `data-fig-req="VR-001 VR-002"`：这张图支撑哪些视觉需求（空格分隔）；
  - 原始证据图加 `data-fig-source="文件#页码或图号"`，便于反查；
- 位图用 `<img src alt>`；**本地相对路径必须真实存在**，不要留空容器或 `[IMG]` 占位；原图、裁剪图、生成的教学图可以并存于同一 `.diag`（组合图合法）；
- 静态元素写在 SVG 里，只有“会动的”用 JS 更新（每个动态元素给唯一 id）；
- **静态降级**：交互图必须同时是一张完整的静态图——JS 失效时 SVG 部分仍可读，图注三要素不依赖交互；
- 标注防重叠：远处标签用细引导线（`<line stroke="#cbd5e1">`）连回对象，不要硬挪坐标；一张图标注控制在 8 个以内，同类信息合并成带单位说明的标签；
- 多套坐标系并存时（如复平面 / 相位三角 / 时间图），必须在图旁注明各自横竖轴基准并给对照表；
- 图号全页唯一（“图 A / 图 B”式编号），checker 会查重；
- 复查方法：整页截图 → `core/scripts/slice_png.py` 切条 → 逐条目视（这一步不能省）。

折叠与侧栏导航的实现引擎在模板内（`core/assets/study-page-template.html`），不要在交互代码里重复造。

交互元素的具体形态（词表高亮、对照卡、网络图、节奏滑块等）由领域适配器决定；本文件只管分级、最低要求与图容器契约。
