## 8. Incremental Impact Checklist

- [ ] 新材料是否只是新增证据，而非新增知识？
- [ ] 是否出现此前未教的 prerequisite？
- [ ] 是否改变某能力的 assessment status？
- [ ] 是否存在修订/冲突，不能静默覆盖？
- [ ] 是否需要结构重排，还是局部 canonical node 更新即可？
- [ ] 未受影响知识的 stable ID / anchor 是否保持不变？
- [ ] 新增内容是否已进入正确位置，而不是简单追加在页面末尾？
